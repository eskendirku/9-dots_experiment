# Эксперимент «9 точек» (Оптимизированная версия)

Статический сайт: `index.html` + `experiment.js` + `style.css`.
Все зависимости и шрифты находятся локально в папке `vendor/`. Эксперимент полностью работоспособен без подключения к интернету.

---

## 🌟 Ключевые нововведения и возможности

1. **Двуязычный интерфейс (RU / EN):**
   - Первым экраном участнику предлагается выбрать предпочтительный язык: **Русский** или **English**.
   - Все экраны, инструкции, шкалы, опросники, модальные окна и уведомления адаптируются под выбранный язык.

2. **Предупреждение о необходимом оборудовании:**
   - После выбора языка участник видит предупреждение о необходимости клавиатуры и мыши (тачпад ноутбука не подходит, прохождение со смартфона невозможно).

3. **Проверка понимания инструкции к задаче:**
   - После ознакомления с инструкцией участнику задаётся вопрос: «Что именно вам необходимо сделать в этой задаче?» с 5 вариантами ответов:
     1. Соединить 9 точек прямыми линиями, не отрывая руки
     2. Соединить 9 точек 3 линиями, не отрывая руки
     3. **Соединить 9 точек 4 прямыми линиями, не отрывая руки** *(правильный ответ)*
     4. Обвести 9 точек прямыми линиями
     5. Я не понял инструкцию/забыл *(возвращает на экран инструкции)*

4. **Подтверждение при нажатии «Сохранить»:**
   - При нажатии кнопки «Сохранить» появляется окно подтверждения:
     *«Вы уверены, что хотите прекратить решение? Вернуться к задаче станет невозможно»*
   - Кнопка **«Вернуться к решению»**: стирает нарисованное, фиксирует текущую попытку и позволяет начать решать заново (аналогично кнопке «Продолжить»).
   - Кнопка **«Закончить эксперимент»**: завершает решение и переводит к опросу.

5. **Расширенный опросник:**
   - В вопрос о поле добавлен вариант: **«Предпочитаю не говорить»** (**«Prefer not to say»**).
   - Добавлен вопрос о формате прохождения: **«В присутствии экспериментатора»** / **«Без экспериментатора»** (столбец `experimenterPresence` в CSV/JSON).
   - В конце опроса добавлен шаг для студентов, которым полагаются баллы: **ввод ФИО, вуза и группы**. Данные сохраняются в столбец `name` CSV-файла и совместимы с анализатором.

6. **Улучшенный финальный экран:**
   - Статус отправки данных DataPipe становится **зелёного цвета** при успешном сохранении.
   - В случае сбоя или оффлайн-режима участник может в один клик скачать CSV-файл прямо с финального экрана и отправить его на почту `alexanderalkuritsyn@gmail.com`.
   - Добавлена просьба поделиться ссылкой с друзьями и знакомыми.

## 🚀 Как запустить

### В один клик
Дважды нажмите на файл **`_START_EXPERIMENT_OPTIMIZED.bat`** в папке `GEM_phd` (или `start.bat` внутри этой папки).
Сервер запустится на `http://localhost:3000`, и браузер откроется автоматически.

### Вручную через Node.js
```bash
node server.js
```
или для запуска без отправки на сервер:
```
http://localhost:3000/?offline
```

### Сборка для GitHub Pages
```bash
npm run build
```
Собранные файлы находятся в папке `dist/`.

## ⌨️ Горячие клавиши

- **F** — Полноэкранный режим (Fullscreen).
- **Y** — Панель настроек / Debug HUD.
- **R** — Стереть линии / начать следующую попытку.
- **T** — Досрочно завершить задачу (перейти к опросу).
- **Пробел** — Начать опрос на вводном шаге анкеты.
- **E** — Открыть страницу детального экспорта на финальном экране.
